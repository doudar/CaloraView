# Caloraview

Caloraview is the selected product name, combining the heat-related root *calor* with *view*. The desktop title, executable, Android helper package and public project branding use this name. The established `accuheat-calibration-export-v1` data-format identifier stays unchanged so previously exported camera calibration remains readable. References to the original vendor APK retain its exact filename as provenance.

## Artwork

The application icon was created and revised through the Skarix MCP endpoint for this project. Its thermal-target reticle uses a centered hollow square and four short ticks. The original rendered output is [skarix-icon.png](../assets/brand/skarix-icon.png), with editable source in [skarix-design.json](../assets/brand/skarix-design.json). The adjacent `icon.png`, `icon.ico`, and `icon.icns` files are derived packaging assets; the renderer uses a smaller copy under `src/renderer/assets/`. These assets belong to the Caloraview identity and do not reproduce the camera manufacturer's branding.

## Preliminary name screening — 7 November 2026

Exact quoted searches for **Caloraview** returned no indexed matches in the general web search used for this review. Additional exact searches targeting Apple App Store, Google Play, Microsoft, npm, PyPI and GitHub also returned no matches. The connected GitHub repository search returned an empty result for this name. These are observations about those searches at that time, not proof that nobody uses the name.

The alternatives screened had clearer existing uses:

- **Thermoryx** already has an industrial sourcing website using that name and contact domain: [thermoryx.com](https://thermoryx.com/).
- **Radioryx** appears in an existing music title: [the artist's Solar Brightness album](https://audiomack.com/heliosphere-rise/album/solar-brightness). That is not evidence of a conflicting software trademark, but it makes the word less distinctive in search results.
- **Calora**, a shortened form, is already used for software including [Calora AI on Google Play](https://play.google.com/store/apps/details?id=ai.calora.app). Keep the full product name **Caloraview**.

## Trademark limits

Official starting points checked were the [USPTO trademark search resources](https://www.uspto.gov/trademarks/search) and [WIPO Global Brand Database](https://www.wipo.int/en/web/global-brand-database). Their interactive registers could not be searched through the text browsing tool in this review: USPTO required its JavaScript interface and WIPO presented a challenge. No claim is made that either register contains zero matching or similar marks.

WIPO describes coverage of international registrations and participating national/regional collections, and also recommends checking national/regional registers. An exact-name web or repository search does not assess similar-sounding marks, unindexed use, geographic rights or goods/services overlap. This screening supports choosing a working project name; it is not legal clearance or a guarantee of worldwide availability. No domain registration, trademark filing or ownership claim was made by this review.
